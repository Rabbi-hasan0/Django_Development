### User models --(django default)
  1. By default fields:
     ```
        * username
        * first_name
        * last_name
        * email
        * password (hashed)
        * is_active
        * is_staff
        * is_superuser
        * date_joined
        * last_login
    ```
  3. Authentication (Login/Logout)
```
     login(request, user)
     logout(request)
     authenticate()
```
